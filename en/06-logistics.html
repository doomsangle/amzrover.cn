Practical Cases
⚠️ Case 1: USPS Oversize/Overage Penalty
Situation: Seller shipped via USPS First-Class Mail with declared weight of 0.5kg, actual weight was 1.2kg (exceeding 1kg limit).
Result: USPS detected the discrepancy during sorting, upgraded to Priority Mail and charged the difference + penalty. Original $3 shipping became $18, with $15 penalty.
Lesson: Always use accurate digital scale. USPS strictly audits dimensions and weight, discrepancies result in high surcharges.
⚠️ Case 2: USPS Size Limit Violation
Situation: Seller shipped a 28x28x28cm package but declared 20x20x20cm, exceeding First-Class Mail size limits.
Result: Package returned with $25 return fee. Reshipment required Priority Mail Large Flat Rate, cost increased from $5 to $18.
Lesson: USPS services have strict size limits. Oversized packages must use appropriate services or will be rejected.
⚠️ Case 3: FBA Shipping Label Error
Situation: Seller shipped FBA ocean freight with incorrect outer box labels, causing Amazon warehouse to fail recognition.
Result: Amazon rejected the shipment, generating $800+ return and reprocessing fees, with 2+ weeks delay in listing.
Lesson: FBA labels must be clear and accurately affixed. Use waterproof labels on multiple sides to prevent peeling.
⚠️ Case 4: Under-Declared Value Customs Detention
Situation: Seller shipped via DHL with declared value of $50, actual value $500.
Result: Detained by destination customs for investigation, generating $300+ inspection and storage fees, 10+ day delay, and tariff difference payment.
Lesson: Declare accurate values. Under-declaration may be treated as tax evasion, causing heavy fines and delays.
✅ Case 5: USPS Cost Saving Best Practice
Situation: Seller shipped multiple lightweight items (0.3-0.5kg each) to US using USPS First-Class International.
Result: Shipping cost only $3-5 per item, saving over 60% compared to DHL, with stable 10-15 day delivery.
Tips: Use USPS for lightweight items (<4.5kg) for lowest cost. Print labels via USPS official website or authorized API for discounted rates.
